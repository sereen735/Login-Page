# 🔐 Modern Login & Signup Page

A clean, modern, and fully responsive **Login and Signup System** built using **HTML5** and **CSS3**. It features elegant gradient headers, interactive floating labels, smooth input state transitions, multi-page navigation, and a refined footer

🔗 **Live Preview:** https://login-page-pr0ject.netlify.app

---

## 🛠️ Built With / Technologies Used

* **HTML5** - Structuring the login form, signup form, input fields, action links, and page footers.
* **CSS3** - Custom styling, CSS Grid centering, linear gradients, smooth transition effects, and responsive footer placement.
* **Google Fonts** - Styled using the "Poppins" typography for a professional UI look.

---

## ✨ Key Features

* **Multi-Page Navigation:** Includes both a login page (`index.html`) and a registration page (`signup.html`).
* **Floating Label Animation:** Dynamic labels that smoothly slide up when an input is focused or filled.
* **Modern Custom Gradients:** Eye-catching gradient designs on the header titles and submit buttons.
* **Centered Layout:** Uses CSS Grid to perfectly center the cards on any screen size.
* **Enhanced Footer:** A clean and professional footer added across pages.
* **Interactive Links:** Includes styled links for password recovery and seamless switching between login and signup forms.
